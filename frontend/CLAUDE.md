# Project Instructions for Claude & AI Agents

Follow all guidelines in `@../AGENTS.md` and `@AGENTS.md`.

## Key Aesthetic Invariants:
1. NEVER use purple gradients, glowing halos, or neon dropshadows.
2. NEVER use pill-shaped (`rounded-full`) buttons. Use `rounded-md` or `rounded-lg`.
3. NEVER add fake reviews, fake ratings, or fake metrics counters.
4. NO vague hero slogans. Keep copy direct, clear, and technical.
5. NO emoji icons (no 🚀, ✨, 💡, 👋, ⚡). Use Lucide SVG icons.
6. NO em dashes (`—`).
7. NO 3D spinning orb slop, cursor animations, or over-the-top scroll effects.
8. Maintain the `/privacy`, `/terms` pages, and custom `icon.svg` favicon.
9. NO "Made with AI" tags anywhere.
